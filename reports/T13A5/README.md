# T13 A5R：谱域 `V*` 管道、置换粒度与信息支撑扫描

> **BOUNDARY — DECLASSIFIED real-device：**本报告只使用 `0624/` 全部 10 条录音；四名说话人均为男声（F0 中位 87–124 Hz），且均为正常音量。未读取 `0625/` 的任何语音条目。结论不得外推到女声、高音 F0、轻声、喊声、噪声环境或佩戴失效。

## 结论

1. `V*` 必须作为 Arm A 的幅度谱接口直接注入。把 `X` 幅度与 `V_real` 相位拼成复谱后再做 ISTFT→STFT，会把不自洽谱投影回 STFT 值域，破坏指定幅度。**通用定式：手工拼装的谱不是信号；除非显式验证 STFT consistency，否则不得把它经波形往返后仍当作原谱。**这与 A3 的评测参照错误属于同一类问题。
2. 修正后，A5R-1a 在 100–800 Hz 得到 `corr(d, loss)=1.000000000000`，最大逐 bin 偏差 `3.815e-06 dB`。`α=1` 四带硬门槛在 d15/d20/d30 全部通过。
3. V_real 的逐录音、同粒度置换显示，扣除选择偏差后的信息量约为 0：d20 的跨录音 `ΔJ3` 中位仅 `+0.00100`，默认录音为 `−0.00252`。旧 A5 pooled `+0.08253` 是统计量、置换粒度及零分布对象不匹配造成的虚高。
4. `β` 从 1 降至 0.5 时，四带 oracle ratio 从约 `0.05–0.08` 陡升至 `0.33–0.45`；继续降到 0.25 或 harmonic-only 后仍约 `0.35–0.45`。这表明信息只集中在部分 bin 时，逐带标量 `w` 是独立且显著的结构瓶颈。
5. A4-3 的原始 `J3=0.63–0.67` 基本全部是逐 `(band,t)` 选择最优 `w` 的选择偏差地板，扣除后约为 0。此前“决策层有 20× headroom”的说法作废。

## A5R-0：构造与静态边界

- 100–800 Hz 内所有 bin 均按 `A*=αA_true+(1−α)A_band` 替换；带外保持 `V_real`。
- `β<1` 时，只有离当前 F0 谐波最近的指定比例 bin 携带 `X` 信息；其余保持 `V_real`。
- 首条录音：修改 13,800 个 bin-frame；相位保持、带外不变、`α=0` 带均值端点与 `α=1` 真幅度端点全部成立。
- F0(V_real) 与 F0(X)：有声判决一致率 85.68%；共同有声 3,667 帧中 91.30% 在 1 semitone 内，中位误差 0.109 semitone。
- 生产代码中的 `V*` 引用为 0。mutation 在生产文件中加入 `build_vstar` 后静态检查命中 2 处。

## A5R-1a：管道断言

门槛在观测前固定为：C=0、100–800 Hz，`|corr(d,loss)−1|≤1e-12` 且最大绝对偏差 `≤1e-5 dB`。

| corr(d, loss) | 最大偏差 |
|---:|---:|
| 1.000000000000 | 3.815e-06 dB |

Mutation：把 bin 3、frame 10 人为抬高 1 dB，断言观测到 `1.000001 dB` 最大误差并失败。

## MR1、妥协、风险与反驳

- MR1 `Y:=S`：G3 recovery 与 J3 均严格为 0。
- `α=1` 物理上不可实现，只用于管道及公式 sanity，不支撑可行性结论。
- β 的 B=9 零分布只用于偏差中位数，不足以给出显著性 p 值；报告不作显著性声称。
- β mask 按离 V_real F0 谐波的距离确定；因此 β 曲线回答“信息支撑稀疏度”而非任意随机稀疏模式。
- A5R 不改变生产模块、参数、门槛或 `KNOWN_FAIL`。
- 对“α=1 全六带也应接近完美”的反驳：构造只承诺 100–800 Hz，800–2000 Hz 未写入 X 信息；把两者聚合会让门槛检验超出其数学前提。
